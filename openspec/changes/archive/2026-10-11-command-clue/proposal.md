# Proposal

## Why

В zsh после `git <Tab>` появляются подсказки: подкоманды с описаниями, имена веток и удалённых репозиториев. Для `tgbot` такого нет. Typer уже умеет генерировать скрипт автодополнения (`add_completion=True` в `cli.py`, есть `tgbot --install-completion` / `--show-completion`), но скрипт не установлен в zsh пользователя, и он подсказывает только статичные вещи: подкоманды и опции. Самое полезное, сохранённые алиасы чатов (`me`, `team`) и ботов (`main`, `alerts`), Tab не предлагает. Из-за этого приходится помнить их или вызывать `tgbot chat list`. Нужно поведение как у `pacman -S <Tab>`: Tab показывает список того, что доступно, то есть сохранённые чаты и ботов.

## What Changes

- Подсказки по Tab для **сохранённых алиасов чатов** (из `tgbot.db`) везде, где ожидается цель: опция `--to`, позиционная цель в `send` и `senddice`, цель после файлов в `sendphoto`/`sendfile`/`sendvideo`/`sendaudio`/`sendvoice`/`sendanimation`/`sendvideonote`/`sendsticker`, а также `NAME` в `chat get-id | default | replace-id | rename | remove`. В описании подсказки показываются chat ID и название чата.
- Подсказки по Tab для **сохранённых алиасов ботов**: опция `--bot` у всех команд и `NAME` в `bot default | rename | remove`. В описании показывается `@username`.
- В медиа-командах файлы по-прежнему дополняются как файлы. Алиасы чатов предлагаются только после первого файла и только если с введённого префикса начинается хотя бы один алиас. Иначе работает обычное дополнение путей.
- После `-` Tab показывает опции текущей команды с описаниями, даже там, где ожидается чат или файл. Это поведение закрепляется тестами.
- Значения опций с фиксированным набором дополняются из этого набора: `--parse-mode` предлагает `html`/`markdown`, а `senddice --emoji` предлагает 🎲 🎯 🏀 ⚽ 🎳 🎰 (сейчас там ошибочно предлагаются файлы).
- Автодополнение работает только на чтение и ничего не выводит при ошибках. Оно не создаёт `~/.config/tgbot`, `tgbot.db` или `config.toml`, не требует `TGBOT_SECRET_KEY`, не ходит в сеть и не расшифровывает токены. Если базы нет или конфиг сломан, просто нет подсказок.
- README: новый раздел «Shell completion» с установкой для zsh (`tgbot --install-completion zsh`, отдельно для oh-my-zsh) и для bash/fish.
- Встроенные команды Typer `--install-completion` / `--show-completion` остаются без изменений.

## Capabilities

### New Capabilities
- `shell-completion`: автодополнение `tgbot` в командной оболочке. Охватывает подсказки сохранённых алиасов чатов и ботов, сочетание с дополнением путей в медиа-командах, гарантии «только чтение / без ошибок» и способ установки.

### Modified Capabilities
<!-- Нет: требования bot-registry, token-encryption и user-config не меняются. -->

## Impact

- Код: новый модуль `src/tgbot_cli/completion.py` (функции-дополнители). `commands/options.py` (`ToOpt`, `BotOpt`), `commands/send.py` (позиционные `rest`/`content`), `commands/chat.py` и `commands/bot.py` (`NameArg`, `old_name`) получают `autocompletion=`. В `db.py` может появиться открытие базы только на чтение.
- Зависимости: новых нет (Typer/Click уже есть).
- Тесты: новый `tests/test_completion.py` (pytest), прогон через `_TGBOT_COMPLETE=complete_zsh`.
- Документация: README и, при необходимости, `skills/tgbot/references/reference.md`.
- Пользователю нужно один раз установить скрипт в zsh. Код не меняет `~/.zshrc` сам по себе, это делает только явный вызов `--install-completion`.
